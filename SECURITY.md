# Security policy

## Reporting a vulnerability

Please report bypasses or vulnerabilities privately through GitHub's
**Report a vulnerability** button (Security → Advisories) or by email to
kirtan11bhatt@gmail.com. Include a minimal input that reproduces the issue.

I aim to acknowledge reports within 3 days.

## Scope

promptshield is a heuristic, defence-in-depth layer. A prompt that evades
detection is a welcome report, but no pattern-based scanner can stop every
prompt injection. Keep least-privilege tool permissions and human confirmation
for sensitive actions regardless of what promptshield reports.
